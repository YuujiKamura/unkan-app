解説
この問題は、トラック（貨物自動車）運転者の「2日（前日・当日および当日・翌日）を平均した1日当たりの運転時間」が2日とも9日時間を超えているか（＝基準違反となるか）を判定する典型的な計算問題です。

📌 判定ルールのおさらい
原則ルール: 2日を平均して1日当たりの運転時間が9時間を超えてはならない。

違反の条件: 「前日と当日の平均」および「当日と翌日の平均」の両方が9時間を超えている場合に、その日は基準違反（＝限度超過）となります。

※片方だけが9時間を超えている場合は、ただちに違反とはなりません。

🔍 各選択肢の検証
1. 【違反 ❌】（正解の選択肢）
1日目（9時間）:

前日（休日）との平均：判定対象外

翌日（2日目: 8時間）との平均：(9 + 8) ÷ 2 = 8.5時間（9時間以下 OK）

2日目（8時間）:

前日（9時間）との平均：8.5時間

翌日（3日目: 11時間）との平均：(8 + 11) ÷ 2 = 9.5時間（9時間超）

👉 片方のみ超過のため OK

3日目（11時間）:

前日（2日目: 8時間）との平均：(11 + 8) ÷ 2 = 9.5時間（9時間超 ⚠️）

翌日（4日目: 9時間）との平均：(11 + 9) ÷ 2 = 10.0時間（9時間超 ⚠️）

👉 両方とも9時間超のため【違反】

2. 【適合 ⭕】
1日目（7h）: 平均 7.5h（OK）

2日目（8h）: 前日平均 7.5h / 翌日平均 9.0h（OK）

3日目（10h）: 前日平均 9.0h / 翌日平均 10.5h

👉 前日平均は 9.0時間（「9時間を超える」ではなく「9時間ちょうど」なのでOK）

4日目（11h）: 前日平均 10.5h / 翌日平均 9.0h

👉 翌日平均が 9.0時間ちょうどのため OK

5日目（7h）: 平均 9.0h（OK）

3. 【違反 ❌】（正解の選択肢）
1日目（10時間）:

翌日（2日目: 9時間）との平均：(10 + 9) ÷ 2 = 9.5時間（OK※片方のみ）

2日目（9時間）:

前日（1日目: 10時間）との平均：(9 + 10) ÷ 2 = 9.5時間（9時間超 ⚠️）

翌日（3日目: 8時間）との平均：(9 + 8) ÷ 2 = 8.5時間（9時間以下）

👉 片方のみ超過のため OK

3日目（8時間）: 前日平均 8.5h / 翌日平均 9.5h（OK）

4日目（11時間）:

前日（3日目: 8時間）との平均：(11 + 8) ÷ 2 = 9.5時間（9時間超 ⚠️）

翌日（5日目: 8時間）との平均：(11 + 8) ÷ 2 = 9.5時間（9時間超 ⚠️）

👉 両方とも9時間超のため【違反】

4. 【適合 ⭕】
1日目（8h）: 平均 7.5h（OK）

2日目（7h）: 前日平均 7.5h / 翌日平均 9.0h（OK）

3日目（11h）: 前日平均 9.0h（ちょうど9h）/ 翌日平均 10.5h（OK）

4日目（10h）: 前日平均 10.5h / 翌日平均 8.5h（OK）

5日目（7h）: 平均 8.5h（OK）

💡 解答のポイント・テクニック
「9時間ちょうど」は違反ではない
「9時間を超える（> 9）」が条件なので、平均が9.0時間の場合は基準内（適合）になります。選択肢2や選択肢4はこの「ちょうど9時間」が含まれており、引っかかりやすいポイントです。

隣り合う2日間の「合計」で考えると早い
「平均9時間超」＝「2日間の合計が18時間を超える（19時間以上）」と言い換えられます。

例: 選択肢1の 2日目〜4日目

2日目＋3日目＝8＋11＝19時間（> 18時間 ⚠️）

3日目＋4日目＝11＋9＝20時間（> 18時間 ⚠️）

3日目を挟む両側がどちらも18時間を超えているため、即座に3日目が違反と判定できます。

９時間越えてたら単純にアウトではないのか
単純に「1日の運転時間が9時間を超えている＝アウト」ではありません。

ここが改善基準告示（労働時間等の改善のための基準）の引っかかりやすい重要ポイントです！

💡 なぜ「1日9時間超」だけで即アウトにならないのか？
ルール上の定義が「1日当たり」ではなく、「2日（前日・当日および当日・翌日）を平均して1日当たり」となっているためです。

業務の波を考慮する特例的ルール
特定の日だけ長距離配送などで運転時間が伸びてしまっても、その前後の日の運転時間が十分に短ければ、2日平均で9時間以下に収まるため違反にはなりません。

⚖️ 判定のルール（2段階チェック）
ある「特定日」について違反かどうかを判定する際は、必ず 前日との平均 と 翌日との平均 の両方を見ます。

（前日 ＋ 当日）÷ 2 ＞ 9時間 か？

（当日 ＋ 翌日）÷ 2 ＞ 9時間 か？

👉 ①と②の「両方」が9時間を超えた場合のみ、その当日の運転時間が「基準違反」となります。
（片方だけが9時間を超えている状態であれば、セーフ＝適合です）

🔍 例で見る（選択肢1の 1日目 と 3日目）
データ：【休日】| 9h(1日目) | 8h(2日目) | 11h(3日目) | 9h(4日目) | 7h(5日目) | 【休日】

1日目（9時間）の場合
前日（休日）との平均：判定なし

翌日（8h）との平均：(9 + 8) ÷ 2 = 8.5時間（9時間以下 ⭕）
👉 1日単体では9時間運転していますが、翌日が8時間と短いため平均8.5時間となりセーフです。

3日目（11時間）の場合
前日（8h）との平均：(11 + 8) ÷ 2 = 9.5時間（9時間超 ⚠️）

翌日（9h）との平均：(11 + 9) ÷ 2 = 10.0時間（9時間超 ⚠️）
👉 前日の組み合わせ（19h）も、翌日の組み合わせ（20h）も、どちらも合計18時間（＝平均9時間）を超えてしまっているため、3日目がアウト（違反）となります。
