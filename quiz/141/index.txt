これ旧基準か
いいえ、こちらは新基準（令和6年4月1日施行の改正改善基準告示）に対応した問題です。

問題文の最後にも「（※法改正により一部改変）」と記載されている通り、令和2年当時の過去問を現在の法規定に合わせて数値をアップデートして出題しているようです。

具体的に新基準となっているポイント（正答となる数値）は以下の通りです。

[ A ] 1ヵ月の拘束時間: 原則「284時間」（※旧基準は293時間）

[ B ] 1年の拘束時間: 原則「3,300時間」（※旧基準は3,516時間）

[ C ] 1日の最大拘束時間: 「15時間」（※旧基準は16時間）

[ D ] 長距離特例の最大拘束時間: 「16時間」

画面下部に表示されている正答インデックス「1, 3, 6, 8」も、それぞれ上記の新基準の数値（Aの①、Bの①、Cの②、Dの②）を指しています。そのまま現在の試験対策として学習して問題ありません。

14時間とか13時間とかみることがあるのはなんだったんだ
「13時間」や「14時間」も、まさしくこの「1日の拘束時間」のルールに登場する超重要キーワードです！

いろんな数字が出てきてややこしいですよね。実はそれぞれの数字には明確な役割があり、以下のような「階段」になっています。

13時間 ＝【大原則】のライン
1日の拘束時間は「原則13時間以内」に収めなさい、という一番基本となる数字です。今解かれている問題文の冒頭にも「13時間を超えないものとし…」としっかり書かれています。

14時間 ＝【努力目標・目安】のライン
原則（13時間）を超えて延長する場合でも、「14時間を超える回数はできるだけ少なくするよう努めること（目安は週2回まで）」というルールがあります。「最大15時間までは延長できるけど、14時間を超えるようなガッツリ長時間労働は週2回までにしてね」というブレーキのための数字です。   

今回の問題の正解であった「15時間」「16時間」と合わせて、「1日の拘束時間の4ステップ」として整理して覚えるとスッキリしますよ。

【原則】 13時間 （基本はここで終わらせる）   

【目安】 14時間 （これを超える延長は「週2回まで」にするよう努める）   

【最大】 15時間 （通常の業務で、どれだけ延長してもここが絶対の上限）   

【特例】 16時間 （宿泊を伴う長距離運送など、特定の条件を満たした時だけ特別に許される上限）   

本試験の引っかけ問題では「原則は15時間とし…（✖正しくは13時間）」のように、これらの数字をわざと入れ替えて出題されることが非常によくあります。「どの数字が、どのポジションのルールか」をセットで意識しておくとバッチリです！

そもそもなんなんだこの多重原則。作ったやつ頭おかしい
そのお気持ち、痛いほどよく分かります。「原則の例外の特例の…」とツギハギだらけで、勉強する側からすると本当に頭が痛くなる構造ですよね。

なぜこんなややこしい「多重構造」になっているかというと、ズバリ「理想（ドライバーの過労死防止）」と「現実（日本の物流事情）」の板挟みになって、国が妥協に妥協を重ねた結果なんです。

このルールの根本を理解するには、「拘束時間」ではなく「休息期間（睡眠など、完全に仕事から離れる時間）をどれだけ確保させるか」からの逆算だと考えると、少しだけスッキリします。

1. 【理想】しっかり休ませたい
令和6年の新基準では、ドライバーの休息期間は「11時間以上与えるよう努める」ことになりました。

24時間 － 11時間（理想の休息） ＝ 13時間（大原則）
国としては、本当は毎日11時間休ませて、拘束を13時間に収めたいわけです。

2. 【現実の壁】渋滞・荷待ち・天候
しかし、運送業はデスクワークと違い、渋滞に巻き込まれたり、現場での「荷待ち時間」が発生したりします。毎日13時間でピタッと業務を終わらせるのは現実的に不可能です。

そこで「まぁ、週2回くらいなら仕方ないから14時間（目安）も目こぼししよう…」という曖昧な努力目標が生まれました。

3. 【絶対の防衛線】これ以上は命に関わる
新基準では、休息期間の「絶対の最低ライン」が9時間と定められました。

24時間 － 9時間（最低限の休息） ＝ 15時間（最大拘束）
これが、今回の問題の[ C ]の答えです。どんなに渋滞しようが「15時間」が通常の運行で絶対に超えてはいけない壁になっているのは、数学的に「最低9時間は休ませるため」です。

4. 【苦しい言い訳】長距離ドライバーはどうするの？
ここで運送業界から「車中泊しながら何日も走る長距離トラックは、15時間ルールじゃ目的地に着かない！」という悲鳴が上がります。

そこで国は「じゃあ…長距離運送で、かつ家に帰れずトラックのベッド等で寝る時だけは、特別に16時間までOKにするからね！」というツギハギの特例（[ D ]の答え）を追加しました。

つまり、作った人が頭おかしいというより、「無理のある日本の物流システムを、法律の力でなんとか過労死ラインの内側に押し込もうとした結果、ルールがフランケンシュタインの怪物のように複雑化してしまった」というのが実態です。

試験問題を作っている側も、「現場がこの複雑な妥協ルールをちゃんと理解して運行管理できるか」を試してきています。理不尽なルールですが、「官僚の苦しい言い訳の産物なんだな」と思いながら数字のパズルを眺めると、少しだけ暗記しやすくなるかもしれません。試験勉強、応援しています！
